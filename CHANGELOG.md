# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-04-25

### Added
- **Audio Player Component**: A new dedicated `AudioPlayer` component for streaming Quran recitations.
- **Recitation Highlighting**: Integrated word-by-word highlighting synchronized with audio playback.
- **Verse Synchronization**: Automatic tracking of the current verse during audio playback.
- **Mushaf Layout Support**: Added support for multiple mushaf layouts including `hafs-v2`, `hafs-v4`, and `hafs-unicode`.
- **Dynamic Themes**: Support for light and dark modes across the view and player components.
- **Responsive Layout**: Improved scaling and aspect ratio management for different screen sizes.

### Changed
- Renamed project from `vite-react-playground` to `open-quran-view-react`.
- Updated `OpenQuranView` props to expose more configuration options.
